Purpose: This allows the modded files that were put in Beyond-All-Reason\data\games\BAR.sdd folder to be playable online with friend(s).


The player's name joining must match with the host and the person joining must have the match password from host. 

The host port will be 8452 which needs to be allowed by the host. This is by clicking the 'Allow port in firewall' button in 'Host a match' tab. 

Join a match by putting in the Host's IPv4 address.

Map list: it loads the map list and minimap images.

Caching: the first scan runs automatically when the window opens and may take a while. Results are cached in a MapCache folder next to the script, so later launches are instant.

Refresh map list: this button rescans after you install new maps.

Typing a map: you can still type a title by hand, since the dropdown is editable.

Note: There is a Arch Linux version of GUI files.
